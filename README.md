AI-Based Resume Shortlisting System 🤖📄
1. Introduction

In the modern job market, Human Resource (HR) departments receive hundreds of resumes for a single job position. Manually shortlisting suitable candidates is time-consuming, repetitive, and prone to human error and bias.

This project proposes an AI-Based Resume Shortlisting System developed using Python and Django. The system automatically scans, analyzes, and ranks resumes based on job descriptions and required skills.

Using Natural Language Processing (NLP), it extracts key information like experience, education, and skill sets, and matches them with job requirements.

Benefits:

Saves HR professionals valuable time

Improves accuracy

Ensures unbiased and efficient shortlisting

Developed using free and open-source tools

4. Key Features

Upload resumes (PDF or Word format)

Automatic extraction of candidate details using NLP

Skill and keyword matching with job description

Scoring and ranking of resumes

Web-based dashboard for HR managers

Export shortlisted results to Excel or PDF

Works offline, no internet or paid APIs required

5. Tools and Technologies

Backend:

Python, Django

Scikit-learn, spaCy, NLTK

Pandas, NumPy

Frontend:

HTML, CSS, JavaScript, Bootstrap

Database:

SQLite 

Deployment:

Local system, free and offline

All tools and libraries are open-source, making this project cost-effective and easy to implement.
